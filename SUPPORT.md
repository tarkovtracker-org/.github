# Support

Need help with a TarkovTracker-org project? Here's where to go:

## 💬 Discord (fastest)

Our [Discord server](https://discord.gg/PpdDwd2M6V) is the best place for usage questions, troubleshooting, and general discussion.

## 🐛 Bugs and Feature Requests

If you've found a bug or want to request a feature, open an issue on the relevant repository using the provided templates:

- [TarkovTracker](https://github.com/tarkovtracker-org/TarkovTracker/issues) — web app ([tarkovtracker.org](https://tarkovtracker.org))
- [TarkovMonitor](https://github.com/tarkovtracker-org/TarkovMonitor/issues)
- [RatScanner](https://github.com/tarkovtracker-org/RatScanner/issues)
- [RatEye](https://github.com/tarkovtracker-org/RatEye/issues)
- [TrackerBot](https://github.com/tarkovtracker-org/TrackerBot/issues)
- [tarkov-data-overlay](https://github.com/tarkovtracker-org/tarkov-data-overlay/issues)

Please search existing issues first — your question may already be answered.

## 🔒 Security Issues

Do **not** open public issues for security vulnerabilities. See our [security policy](SECURITY.md) for private reporting options.

## 📚 Documentation

Each repository's `README.md` contains setup and usage documentation for that project.
