# Support Directory

Need help with a TarkovTracker-org project? Use the routing directory below to find the fastest way to get assistance. Directing inquiries to the right channel helps you receive quicker answers and keeps issue trackers focused on actionable bugs and features.

---

## Before Opening an Issue

To help our volunteer maintainers triage and fix problems efficiently:

1. **Search Existing Issues:** Check both open and closed issues in the target repository to avoid duplicates.
2. **Test on Live App:** For web app issues, verify whether the problem persists on the latest production deployment at <https://tarkovtracker.org>.
3. **Use the Structured Templates:** Provide complete reproduction steps, error logs, screenshots, and browser/OS details.
4. **One Problem per Ticket:** Keep issues focused on a single topic so maintainers can prioritize and track resolution clearly.

## What We Cannot Help With

- **Battlestate Games / Escape from Tarkov game client:** We are an independent open-source community project, not Battlestate Games. Contact BSG support for account, launcher, purchase, or ban inquiries.
- **Third-Party Service Outages:** Infrastructure issues on Cloudflare, Supabase, Discord, or GitHub should be checked against their respective official status pages.
- **Upstream Data Inaccuracies:** Data originating from `json.tarkov.dev` that is not part of our overlay should be reported upstream to the tarkov.dev team.
